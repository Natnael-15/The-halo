# The Halo Residences | Luxury City Living

An immersive, cinematic real-estate showcase for **The Halo**, a luxury residential tower in Mayfair. The experience highlights signature residences, architectural amenities, a curated neighbourhood concierge, and private viewing scheduling.

## Experience Highlights

- **Hero Showcase:** Architectural hero framing with editorial typography and luxury CTAs.
- **Residences Portfolio:** Signature suites with pricing, layouts, and curated feature lists.
- **Amenities Gallery:** Sky pool, residents lounge, and wellness centre highlights.
- **Neighbourhood Concierge:** Interactive map-style section with Mayfair landmarks.
- **Private Viewing Form:** High-touch scheduling experience with concierge details.

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000` in your browser.

## Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Motion (Framer Motion)
- **Icons:** Lucide React
